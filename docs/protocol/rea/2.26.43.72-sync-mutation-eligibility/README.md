## Offline defect reproduction

`pre-fix-reproduction.rs` is a standalone synthetic public-API probe, run before
editing collection code, against the then-current local library. No real account,
keys, randomness output or network is recorded. It initializes one logical index
with a synthetic key, replaces/removes that same index with a second synthetic
key, and prints only index-count/boolean/error results. Output is retained as
`pre-fix-reproduction.txt`; this records the pre-fix defect, not current behavior.

Reproducer was run using an outside-checkout Cargo package depending on local
`crates/whatsapp-api`, features experimental-signal-crypto,experimental-noise,
experimental-transport, with `cargo run --offline --quiet --manifest-path <lab
repro>/Cargo.toml --target-dir target`. Native row semantics come from the
separate APK evidence; this probe only demonstrates Rust behavior.
